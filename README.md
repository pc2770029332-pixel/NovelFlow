# NovelFlow · AI 小说全流程创作工作台

> 一个本地运行的多 AI 协作小说创作系统：**背景设计 → 章节细纲 → 主笔创作 → 润色修改 → 自动归档**，五步流水线一条龙完成。

## ✨ 特性

- 🎭 **五个 AI 角色分工协作**：背景设计师、细纲设计师、主笔、润色师、归档助理，各司其职
- 🔑 **按角色独立配置模型**：每个角色可单独填写 API Key、端点与模型，支持任意 OpenAI 兼容接口
- 📡 **实时流式输出**：SSE 推送每一步的生成进度与正文内容，边写边看
- 📚 **逐章串行创作**：每章带着「世界观 + 细纲 + 前情提要」生成，保证上下文连贯
- ✨ **自动润色**：初稿完成后自动逐章润色，语病、节奏、风格统一
- 📦 **一键归档**：自动生成作品卡、简介、人物表、完整书目与全书文档，可直接下载
- 💾 **本地存储**：所有产物保存到 `output/` 目录，数据完全由你掌控

## 🚀 快速开始

### 环境要求

- Python 3.9+
- 一个 OpenAI 兼容的 API 端点（OpenAI / DeepSeek / Kimi / Ollama / LM Studio / vLLM 等）

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/pc2770029332-pixel/NovelFlow.git
cd NovelFlow

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
python run.py
```

启动后浏览器访问 **http://127.0.0.1:8000**，在「AI 角色配置」中填入你的 API Key，填写小说信息，点击「🚀 开始全流程创作」即可。

> 💡 想配置环境变量？参考 `.env.example` 复制为 `.env` 后填写即可（页面中填写的配置优先）。

## 📖 使用指南

### 1. 配置 AI 角色

| 角色 | 职责 |
|------|------|
| 🌍 背景设计 | 世界观、人物设定、力量体系、势力版图 |
| 🗺️ 章节细纲 | 逐章细纲：冲突、悬念、钩子 |
| ✒️ 主笔创作 | 逐章撰写正文 |
| ✨ 润色修改 | 语病修正、节奏优化、风格统一 |
| 📦 自动归档 | 作品卡、简介、人物表、全书导出 |

- **默认配置**：其他角色未勾选「自定义」时自动继承
- **跟随默认**：角色字段锁定并实时同步默认配置
- **复制到全部角色**：一键把默认配置铺到所有角色
- API Key 只会在本地保存，页面上以掩码形式显示

### 2. 填写小说信息

书名、题材、主题、一句话创意、目标读者、章节数、每章字数，补充要求可选。

### 3. 创作流程

1. **背景设计**：AI 先生成完整世界观设定
2. **章节细纲**：基于背景逐章设计细纲
3. **主笔创作**：逐章生成正文，实时流式显示
4. **润色修改**：每章初稿立即润色
5. **自动归档**：汇总生成归档文档

运行中可在「实时输出」面板看流式文本，在「正文」标签页查看初稿/润色稿对比，完成后点击「⬇️ 下载全书」获取归档文件。

### 4. 历史记录

点击顶栏「🕘 历史记录」可查看本次服务运行期间的所有工作流（重启服务后内存记录清空，但 `output/` 目录中的归档文件不会丢失）。

│       ├── index.html

## 🔌 支持的服务商

任何 **OpenAI 兼容** 的接口都可以用，只需填对 Base URL 与模型名：

| 服务商 | Base URL | 模型示例 |
|--------|----------|----------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Kimi/Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| Ollama（本地） | `http://localhost:11434/v1` | `qwen2.5:7b` |
| LM Studio（本地） | `http://localhost:1234/v1` | 本地加载的模型 |

## 🔧 常见问题

**Q: 启动后页面能打开，但创作时报错？**
检查 API Key 是否填写正确、Base URL 是否可访问、模型名是否被服务商支持。

**Q: 能中途停止创作吗？**
当前版本不支持手动中断（计划中），刷新页面不影响后台任务，可通过「历史记录」重新进入查看进度。

**Q: 角色可以全部用同一个模型吗？**
可以。只填「默认配置」即可，所有角色自动继承；或点「复制到全部角色」。

**Q: 输出保存在哪里？**
`output/<书名>_<时间戳>/` 下，包含中间产物、完整归档 `archive.md` 与全书正文 `novel.md`。

## ⚠️ 注意事项

- API Key 仅保存在本机 `settings.json` 中，不会上传到任何第三方
- 请遵守各模型服务商的使用条款，AI 生成内容需人工审核后使用
- 长篇小说会消耗大量 tokens，建议先用小章节数试运行
